Conjuntos de dados oficiais

Os links abaixo levam às páginas dos conjuntos de dados ou à publicação oficial que utilizamos como referência. Nessas páginas, consulte os arquivos disponíveis, a descrição, os períodos cobertos e a data da última atualização.

  • Porto Alegre — ITBI, Portal de Dados Abertos. O conjunto indica licença Creative Commons Attribution (CC BY).
  • São Paulo — Dados das Transações Imobiliárias com recolhimento de ITBI, Secretaria Municipal da Fazenda. A página informa o conteúdo e a periodicidade de atualização dos arquivos; confira os termos de uso aplicáveis antes de republicar os dados.
  • Belo Horizonte — ITBI Relatórios, Portal de Dados Abertos. Consulte os recursos e o dicionário de dados; a licença aplicável deve ser confirmada na página oficial vigente.
  • Fortaleza — Transações Imobiliárias com recolhimento de ITBI, Portal Fortaleza Dados Abertos. O catálogo do portal classifica o conjunto com CC-BY; confirme o metadado atualizado na página original.
  • Recife — Imposto sobre Transmissão de Bens Imóveis (ITBI), Portal de Dados Abertos. O conjunto indica a Licença Aberta para Bases de Dados (ODbL).

As licenças e condições de reutilização não devem ser presumidas como iguais entre municípios. Antes de republicar ou redistribuir os arquivos, confira a licença, as atribuições exigidas e as condições de uso indicadas na fonte oficial.

Os endereços dos arquivos e a disponibilidade dos conjuntos podem mudar. A fonte municipal é a referência para confirmar a versão mais recente e os metadados de cada publicação.

O que pode variar entre as fontes

  • Período coberto e frequência de atualização.
  • Nomes, formatos e preenchimento dos campos.
  • Presença de dados ausentes, correções ou registros retificados.
  • Critérios necessários para calcular indicadores comparáveis.

Para entender como essas diferenças são tratadas e como interpretar os resultados, consulte Metodologia e Fontes ou Estatísticas.

Como conferir a origem de um dado

Para uma conferência reproduzível, comece pelo município e pelo período consultado. Abra o portal oficial correspondente acima e procure a descrição do conjunto, os arquivos disponíveis, o dicionário de dados quando houver e a data da última atualização informada pelo órgão responsável.

  1. Confirme se o conjunto cobre o ano que deseja consultar.
  2. Leia a descrição dos campos e as unidades utilizadas, principalmente valor monetário e área.
  3. Confira se o portal informa licença, atribuição obrigatória ou condições específicas para reutilização.
  4. Ao comparar anos ou municípios, verifique se as definições e a cobertura são suficientemente semelhantes.
  5. Se o portal tiver sido reorganizado, use a busca interna do próprio portal para localizar o conjunto pelo nome; não presuma que um endereço antigo continue válido.

Os links desta página são referências para os portais oficiais conhecidos. A disponibilidade, os nomes dos arquivos, os metadados e as licenças podem mudar. A informação atual publicada pelo órgão responsável prevalece sobre este resumo.
