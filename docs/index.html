itbidata

Sua fonte de inteligência para preços de imóveis

Consulte o histórico de transações reais de ITBI, direto dos dados abertos das prefeituras.

Dados: Prefeitura Municipal de Porto Alegre — dadosabertos.poa.br, sob licença Creative Commons Atribuição (CC-BY).

O itbidata é um projeto independente, sem vínculo com nenhuma prefeitura. As informações têm caráter informativo, incluindo os valores de correção monetária (calculados automaticamente a partir de índices públicos). Não substituem certidões oficiais nem assessoria jurídica ou financeira — confira sempre a fonte original antes de qualquer decisão.
